# «Киносфера»

Мы сделали сайт онлайн кинотеатра с каталогом фильмов и сериалов. Данные загружаются из открытого API. При каждом открытии каталога появляется новая подборка.

## Что есть в проекте

1. Две HTML страницы: каталог и избранное.
2. Адаптивная вёрстка по принципу mobile first.
3. Сетки на Flexbox и Grid.
4. Загрузка данных через `fetch`.
5. Проверка ответа через `response.ok`.
6. Поиск по названию.
7. Фильтр каталога по жанрам.
8. Кнопка обновления со случайной подборкой.
9. Карточки с постерами, рейтингами и жанрами.
10. Окно с подробной информацией.
11. Избранное с сохранением в `localStorage`.
12. Состояния загрузки, пустого результата и ошибки.
13. Кнопка повторного запроса при ошибке.

## Публичный API

В проекте используется [TVmaze API](https://www.tvmaze.com/api). API работает по HTTPS, доступен из браузера через CORS и не требует секретного ключа.

Используемые запросы:

1. `GET https://api.tvmaze.com/shows?page={page}`: случайная подборка.
2. `GET https://api.tvmaze.com/search/shows?q={query}`: поиск по названию.
3. `GET https://api.tvmaze.com/shows/{id}`: загрузка избранного.

## Состояния приложения

1. Во время запроса показывается «Загрузка…».
2. Для пустой выдачи показывается «Ничего не найдено».
3. При ошибке выводится понятное сообщение и кнопка «Повторить запрос».

## Запуск проекта

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который Vite покажет в терминале.

## Сборка

```bash
npm run build
```

Готовая сборка появится в папке `dist/`.

Для локальной проверки сборки:

```bash
npm run preview
```

Постеры, названия, описания и рейтинги загружаются из TVmaze API.
